# My_Portfolio / Next15 TypeScript Portfolio (Final Scaffold)

## What's included
- Next.js 15 + TypeScript (App Router)
- Tailwind CSS (v3.4.10)
- GSAP + ScrollTrigger hook
- Swiper for horizontal projects (cards)
- Sanity client (+ image builder)
- Placeholder components and pages, all .ts/.tsx
- Your uploaded logo included at /public/logo.png

## Quick start
1. unzip and `cd next15-ts-portfolio-final`
2. `npm install`
3. copy `.env.local.example` to `.env.local` and set Sanity vars if needed
4. `npm run dev`
5. open http://localhost:3000
